# Contributing

## Branches
- Branch from `main`: `feat/<short-name>`, `fix/<short-name>`, `chore/<short-name>`
- Keep branches short-lived; open a draft PR early

## Commits
Use [Conventional Commits](https://www.conventionalcommits.org): `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`

## Pull requests
- Fill in the PR template
- At least 1 approval; all conversations resolved; checks green
- Squash and merge; the branch is deleted automatically

## Secrets
Never commit secrets, `.env` files or client data. Use repository or organization secrets.
